# 机场搜索、白色尾迹和暂停菜单（2026-09-09）

## 参考与边界
用户截图明确显示：输入长春后，结果被弹窗底边裁切。此前用户 21.68 秒 FocusFlight 录屏的暂停菜单可确认“放弃专注 / 飞行模式 / 保持屏幕常亮”。该视频未展示原版机场搜索，不能声称本次搜索布局逐像素复制原版。

## 根因和修复
- 搜索结果原为绝对定位，home.css 又把外层固定在底部且允许外层滚动。1280×800 浏览器复现，首条结果底部832px，弹窗底部768px，必须滚动。移除冲突的首页覆盖规则，结果进入正常文档流，搜索浮层放到视口上方。修复后相同检查：结果底337px，弹窗底362px。原选择、确认和本地机场数据不变。
- 原尾迹被截断到已飞过距离，早期距离不足，整段尾迹容易被机身及机场标记盖住。第一次调整地图图层仍不够清楚，实际截图未通过。最终使用独立 SVG 双线渐隐尾迹，与飞机当前位置/航向一起经地图投影更新；相机变化时同步投影，结束时清空。尾迹不参与航程距离或计时，原 RAF/Date.now/飞机位置逻辑不变。
- 暂停二级页面增加两项真实操作：飞行模式打开固定 Windows 通知设置 URI，由用户自行开启勿扰；屏幕常亮使用线程范围的显示请求，关闭、取消、正常完成以及 WebView 重载时释放。程序退出时线程请求随之结束，不修改电源计划或注册表。
